01 登録・認証

  1. 会員登録で必要事項を入力します。
  2. 登録先に届いた確認メールのリンクを開き、メールアドレスを確認します。
  3. ログインして、購入・出品などの操作へ進みます。

メールアドレスの確認

登録したメールを受け取れるか確認します。届いたメール内のリンクを開いてください。

認証アプリの6桁コード

販売管理・売上などの重要操作で使う追加認証です。確認メールは送信されません。スマートフォンの認証アプリに表示されるコードを入力します。

書類による本人確認

身分証と自撮りによる確認です。6桁コードとは別の手続きで、本人確認画面から進めます。

「認証アプリで本人確認」と表示されたら

  1. 設定済みの認証アプリを開き、「ツールバコ」の項目を探します。
  2. 表示中の6桁コードを、ツールバコの画面に入力します。
  3. 「確認して続ける」を押します。確認はこの端末で10分間有効です。

初めての場合は、認証アプリの登録画面の案内に沿って設定してください。同じスマートフォンで設定するときやQRコードが読めないときは、「スマートフォン1台で設定する・手動で入力する」を使えます。

コード・登録用QRコード・セットアップキーは、問い合わせやチャットへ送らないでください。

02 ツールを購入する

  1. ツール一覧で検索し、商品詳細を開きます。
  2. 価格・提供方法・動作環境・利用条件・納期を確認します。不明点は購入前に販売者へ相談します。
  3. 購入画面で商品と金額を確認して手続きを進めます。処理中と表示されたら、購入を繰り返さず結果を待ってください。
  4. 購入ライブラリや購入履歴から、利用方法や取引状況を確認します。取引ルームで納品する商品は、ルームで販売者とやり取りします。

商品の掲載審査から公開まで

現在は運営担当者が手動で掲載内容を確認します。商品登録時に審査一覧へ入るため、最初の申請操作は不要です。既に「安全チェック待ち」となっている商品も対象です。

  1. 販売者：商品説明・利用条件・個人情報や外部サービスの扱いを記入し、商品を登録します。
  2. 運営担当者：運営管理 → 商品掲載・独占譲渡審査から商品を開き、内容を確認します。確認項目と審査記録を入力して承認、または修正依頼を送ります。
  3. 販売者：サイト内通知、または販売管理 → 編集・受付設定 → 掲載審査で結果を確認します。要修正の場合は修正・保存後に再審査を申請してください。
  4. 承認されたら販売管理で「公開する」を押します。承認だけでは公開されません。

承認後に商品説明・画像・価格・納品条件などを変更すると、公開を休止して再審査になります。受付枠だけの変更では再審査になりません。

掲載審査とファイル検査の違い

掲載審査は説明・販売条件の確認です。AIのコード解析、動作検証、安全性の保証ではありません。取引ルームの納品ファイルには別途ウイルス検査を行います。未確認の事項があれば販売者に確認してから利用してください。

03 出品・商品画像を変更する

  1. 出品画面で商品名・説明・販売条件・提供方法を入力します。
  2. 商品画像を選択し、権利や禁止出品物の確認をして「この内容で出品する」を押します。
  3. 販売管理で公開状態と審査状況を確認します。登録だけで購入可能になるとは限りません。

登録済み商品の画像を変更する手順

  1. 「販売管理」→ 対象商品の「編集・受付設定」を開きます。
  2. 「商品画像」でJPEG・PNG・WebPのファイルを選びます（5MBまで）。
  3. 「変更を保存」を押し、「変更を保存しました」が表示されるまで待ちます。ファイルを選ぶだけでは保存されません。
  4. 「プレビュー」で公開ページの画像を確認します。

商品画像は公開されます。個人情報・秘密情報が写っていない画像を使ってください。

公開と決済・売上受取の設定は別です。販売開始前に「販売管理」の「決済・口座設定」で必要な手続きを確認してください。

04 取引・納品・売上を確認する

  1. 購入者は「購入履歴」、販売者は「販売管理」から対象の取引ルームを開きます。
  2. 作業内容・納期・修正内容をルーム内のメッセージで確認します。
  3. 販売者は「正式な納品」に説明や利用手順を記載します。ファイル添付欄が表示されている場合は、その場でファイルを選んで「正式に納品する」を押します。
  4. 購入者は納品物を確認し、問題がなければ「納品を承諾する」を押します。修正が必要な場合は、画面の「修正を依頼する」やメッセージから相談してください。画面に表示される確認期限も確認します。
  5. 販売者は売上・振込で売上と振込状況を確認します。売上受取には本人確認・決済口座の設定などの条件があります。

キャンセルや返金は、対象の取引ルームに表示される手順から進めてください。処理中の申請を繰り返さず、解決しない場合は運営へお問い合わせください。

05 困ったとき

認証のメールが届きません

まず画面を確認してください。「認証アプリに表示された6桁のコード」を求められている場合、メールは送信されません。認証アプリの使い方を確認してください。

登録確認・パスワード再設定のメールの場合は、迷惑メールフォルダ、登録アドレスの入力間違い、受信制限を確認してください。届いたメールがツールバコからのものと確認できたら、迷惑メールを解除できます。解決しない場合は、実行した操作と時刻を運営へお知らせください。

6桁コードが通らない・認証アプリが見つかりません

登録したツールバコの項目を選び、新しいコードに切り替わってから入力してください。端末の日時が自動設定になっているかも確認します。

機種変更や紛失でアプリを使えない場合は、運営へ相談してください。パスワード再設定だけでは、この追加認証は解除されません。

「変更を保存」を押しても進みません

画面の入力エラーと必須項目を確認してください。画像はJPEG・PNG・WebP、5MB以内です。エラー画面から戻った場合は、ファイルの選択が残っているかも確認します。

保存完了の表示が出るかを確認し、進まない場合は操作した時刻・商品名・表示されたエラーを運営へお知らせください。

「準備中」や「審査待ち」と表示されます

画面に記載された設定や審査が終わるまで、その機能を利用できない状態です。本人確認画面から戻っただけでは確認完了になりません。表示された状態を確認し、長く変わらない場合は運営へご連絡ください。
